Ctrl⇧N New chat session

/ Search sessions
CtrlE Export chat as Markdown
Esc Close gallery / panels
🧊 Interactive 3D Viewer
🖱️ Drag to rotate the model, scroll to zoom in/out, and right-click drag to pan.
👆 Click on any component to see its real-world specs, pinout, and applications.
⚡ Electron flow toggle shows animated current/particle flow through the circuit.
🔧 Circuit Builder lets you place components and simulate circuits interactively.
💬 Smart Chat Features
🎯 Ask about any engineering concept and get detailed explanations with live 3D models.
📝 Use Quick Actions below the chat for practice problems, summaries, and project ideas.
🌙 Theme toggle (top-left) switches between dark and light mode. Your choice is saved.
📥 Export your chat as a clean Markdown file for revision notes.
